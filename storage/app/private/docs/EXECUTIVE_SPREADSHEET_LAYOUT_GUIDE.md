## Suggested Presentation Order Inside The Workbook

- place the dashboard first
- place monthly view second
- place ROI calculator third
- place assumptions last

## Formatting Recommendations

- freeze the top row on every sheet
- format NGN fields as currency with thousands separators
- highlight manual entry cells in a light fill color
- bold section rows in the ROI calculator sheet
- add charts only on the dashboard sheet

## Suggested Dashboard Charts

- clustered bar chart for full contract value across the 10, 25, and 50 campus scenarios
- line chart for monthly cash collection by scenario
- stacked bar chart for subscription, implementation, and add-on revenue mix

## Modeling Note

The executive views simplify the raw model into board-friendly tabs. The source normalized files remain available if you want to rebuild the model into a more formula-driven spreadsheet later.
